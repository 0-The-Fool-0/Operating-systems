# Операционные системы — лабораторные работы на C++

[English version](README.md)

Коллекция отдельных лабораторных проектов на C++, посвящённых системному программированию. Темы идут от файловых записей и многопоточных вычислений к синхронизации, обмену данными между процессами и клиент-серверному приложению для работы с записями сотрудников.

## Лабораторные работы

| Каталог | Основные темы |
|---|---|
| `Lab 1/` | Бинарные записи сотрудников, отдельные процессы Creator/Main/Reporter, формирование отчёта и проверки GoogleTest. |
| `Lab2 CMake C++17/` | Вычисление минимума/максимума и среднего значения, многопоточная реализация и тесты. |
| `Lab3 Cmake C++17/` | Работа с общей памятью/массивом и маркерами, тесты логики синхронизации. |
| `Lab4/` | Очередь на базе файлов, программы sender/receiver и тесты очереди. |
| `Lab5/` | Клиент и сервер, репозиторий записей сотрудников, менеджер блокировок записей и тесты. |

У каждой лабораторной собственная конфигурация CMake; единого исполняемого файла для всего репозитория нет.

## Сборка и тесты

Потребуются компилятор с поддержкой C++17 и CMake. Для конкретной лабораторной запускайте CMake из её каталога. Например:

```powershell
cmake -S "Lab2 CMake C++17" -B "Lab2 CMake C++17/build"
cmake --build "Lab2 CMake C++17/build" --config Debug
ctest --test-dir "Lab2 CMake C++17/build" -C Debug --output-on-failure
```

Это пример предполагаемого процесса сборки, а не подтверждённый результат. Проверьте CMake-файл нужной лабораторной на требования к компилятору, платформе и зависимостям. Некоторые части ориентированы на Windows API, поэтому переносимость может различаться.

## Учебный контекст

Это академические задания по процессам, потокам, синхронизации, файловому вводу-выводу, межпроцессному взаимодействию и конкурентному доступу к записям. Репозиторий не следует рассматривать как готовую промышленную библиотеку или службу.
